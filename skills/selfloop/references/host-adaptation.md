# 把「不是自己的」页面改造成可驱动宿主

> 闭环引擎不认你的页面，它只认三件事：**参数能改、画面能冻、数值能回读**。
> 页面不是你写的，所以这三件事得你去补。下面这份清单是一次第三方 3D 特效台（轻量 WebGL2、动画是 `t+seed` 纯函数、同步 IIFE 自启）跑通之后回头写的，每一步都是被「跑得起来但量不到东西」逼出来的。

## 0. 开工前先判三件事

1. **能拿到源文件吗**：要加配置注入、冻结开关、回读接口这三样，源码改不动就换方案（不要用 Playwright 注入去硬掰，注入时机永远比 `init()` 早不到）。
2. **原素材是别人的吗**：是 → 只改副本，把原目录封进 `guard.protectPaths`（相对 adapter 目录或 `%ENV%` 模板都行），纪律是那边一个字节都不许动。
3. **能不动渲染核心吗**：本案 `effect.js` 一个字节没改（sha256 与原文件相同），因为动画本来就是 `t+seed` 的纯函数。**先想办法不改美术/渲染那块**，改的越少，越能证明「变好是参数的效果，不是我把画面重写了」。

## 1. 五步改造

### ① 参数提前注入（最容易白干的一步）

同步 IIFE 的宿主，脚本一执行就干三件事：读 `PARAMS` → 建滑块 → `init()`。滑块建的时候就把 `d.value` 抄进去了，所以**事后**改 `PARAMS[k].value` 对画面没用（对「参数已经进了页面」这件事更是完全没用）。

做法：把 `<script src="game.js">` 换成自己的 bootstrap，例如 `host-init.js`：

```
fetch 配置 → 逐键覆盖 PARAMS[k].value（按各自 min/max 夹紧，未知键记 ignored）
           → 再动态插 <script src="game.js">
           → 置 window.__cfgLoaded
```

判据：改配置文件 → 回读 `params()` 与文件一模一样。

坑：`file://` 下 `fetch` 被 CORS 拦（origin=null），配置根本读不到。**必须走静态服**（包自带 `static/server.mjs`，全部 `no-store`，改完刷新就是新值）。读不到时退回默认值 + 记一条错误，但 `__cfgLoaded` 照样置真——否则页面永远不就绪，你会以为是页面卡死。

### ② `readyExpr` 要双标记

「首帧画完了」和「参数生效了」是两件事，只判前者会抢在参数落地之前截图。

- `window.__ready`：首帧 rAF 回调里置真；
- `window.__cfgLoaded`：配置拿到**或明确退回默认值**之后置真。

`readyExpr` 必须两个都真。少了后者，症状很难看：每一轮都截到「默认参数的那张图」，所有候选长得一样，距离曲线是一条平线，你会去怀疑搜索算法——其实是拍照早了一帧。

反证：把 `readyExpr` 退回只判 `__ready`，然后把某个参数改大一档，画面 sha 应该不变（拍照早于生效）。变了说明你运气好、时序刚好对上，这种「刚好」不要留。

### ③ 隐藏所有会变的 DOM

逐字节比对的天敌是 HUD。一行 `fps · t` 每 500ms 重写一次，`Page.captureScreenshot` 截的是**整页**（不只是 canvas），所以连拍两张必然不同，`verify: strict` 永远红。

做法：冻结模式下把 `#ui` / `#stat` 之类隐藏掉，**并且停掉那行 DOM 写入**。只靠 CSS 藏不够稳（可能有 opacity / transform 动画在跑），最稳的是「冻结时压根不写」。

顺带排查一遍别的会变的东西：滚动条、加载动画、光标闪烁、`setInterval` 驱动的文字、video 播放、CSS animation。**冻结就得是一个像素都不动**。

### ④ 冻完就退 rAF，别留任何时间源

`frame()` 末尾改成：

```
if (FROZEN) { window.__frameDone = true; return; }
requestAnimationFrame(frame)
```

冻结模式下**只画一帧**，之后页面没有任何时间源。这条是 `verify: strict` 能过的根基。

判据：同一个 URL 连拍两张，sha 必须相同（`verify: strict` 会替你验）。

### ⑤ 给一个扁平回读接口喂 `readbackExpr`

新开一个 `window.<你的名字>.params()`，返回扁平的 `{参数: 数值}`。为什么要扁平：`iter.ps1` 是**逐键**比 want/got 的，嵌套对象、带单位字符串都没法比。

顺手把这几个也加上（调试时省一半时间）：

- `setParam(k, v)`：带 min/max 夹紧 + 返回值（证明真的吃进去了）；
- `setT(sec)`：冻结时顺手重画；
- `redraw()` / `freezeInfo()`：状态自证。

坑：**停 rAF 之后改参不会重画**。冻结模式只画一帧，`setParam` 之后画面还是旧的。所以 `setParam` / `setT` 在冻结态要补一次 `frame(0)`。引擎走「改配置 → 重载」不受影响，但手工调试第一次踩这个会怀疑人生。

## 2. 判据阈值必须实测，不能抄

这是本案最贵的两条反例，两种都是「跑得起来但量不到东西」——比报错更坏，因为数字一直在那儿，你看不出它没量：

| 阈值 | 症状 | 为什么 |
|---|---|---|
| `cov` 用 `luma:40` | 恒等于 **0.98** | 整幅天空 + 地面都在 luma 40~170，全图都算「亮」 |
| `bbox` 用 `luma:150` | 宽度恒为 **640**（=画幅宽） | 地平线那条亮带撑满整行 |

做法：挑一个**真旋钮**（本案 `length` 5.8 → 6.38），在每个候选阈值下看指标动不动。不动就是没量，往上加。

本案最终 200：`cov` 0.0146、`bboxW` 277px，对 `length` / `radius` 的响应清清楚楚（277px → 303px）。

色系维度另算：暖色特效用 `warmFrac`，并且**把 `rMin` 放松**（140 → 120），因为爆炸球白芯 r≈255 但 r/g 只有 1.05，卡太死会把画面里最亮的那块漏掉。

> 反向也成立：阈值不能只为「好看」，要为「有梯度」。指标恒满和指标恒零一样废。

## 3. 冻帧协议怎么选

| 页面有什么 | 选什么 | 还要补什么 |
|---|---|---|
| `window.step` + `window.playFx` | `noloop-step` | `freeze.stepMs`；`clock` 写 `wall` 或 `virtual` |
| 只有 `?time=<秒>` 这类一次性参数 | `url-time` | `clock` 写 `n/a`（写 `virtual` 会被拒）；`verify: strict` |
| 两个都没有 | 先去改造页面（§1 五步），别硬选 | — |

选错不是「效果差一点」，是 `iter.ps1` 自检**直接拒**：`noloop-step` 会实测 `step|playFx` 存不存在；`url-time` 会连拍两张比 sha。

`?time` 的语义必须在文档里写死：是秒还是毫秒、是整条时间轴还是循环内相位。本案 `duration=1.7`，`1190ms → 1.19s → t=0.70`：射线全长已出、命中冲击球正亮，三块内容都在画面里——**选时刻要选「内容最全」的那一帧**，别选 0.05s，那时候画面几乎是空的，判据全零，搜索会学出奇怪的东西。

## 4. 反证要求：必须有一条「故意不冻」

「两张相同」可能只是页面根本没画东西——黑屏当然两次一样，静态图也一样。

所以每个宿主都要留一条对照：**去掉冻结开关（本案是去掉 `?time=`）再连拍两张，必须不同**。

本案：有 `?time=` → 两张 sha 相同；去掉 → 不同。两条合起来才证明「唯一的时间源被清零了」，而不是「这张图是死的」。

把这个对照写进施工记录 / 证据包，**别只写结论**。只写「验过了」的反证，等于没验。

## 5. 完工自检（五条，全过才算接通）

1. 改一档参数 → `params()` 回读一致；
2. 改一档参数 → 画面 sha 变；
3. 同 URL 连拍两张 → sha 相同；
4. 去掉冻结 → 连拍两张 → sha 不同；
5. 小预算跑一轮（`-Budget 12`）能出 best，且 `cleanup` 后配置文件哈希回到基线。

第 5 条别跳过：前四条都过、闭环仍然跑不出梯度的情况实打实发生过（活性扫描里某一根就是死的）。

## 6. 症状速查

| 症状 | 先查 |
|---|---|
| 每轮距离一模一样 | `readyExpr` 缺「配置落地」标记；或参数压根没进页面（回读不一致） |
| `verify: strict` 一直红 | HUD / 时间源没清干净（§1 ③④） |
| 指标恒 0 或恒满 | luma 阈值没实测（§2） |
| 单次评估很慢（几秒） | 走了 Playwright 的 Chromium 下载；改系统 Edge + SwiftShader 三件套 |
| 截图是空白 canvas | `--screenshot=` 抢在 rAF 画一帧之前；改走 CDP + `readyExpr` 轮询 |
| `file://` 读不到配置 | CORS（origin=null），必须走静态服 |
| 改了参数画面没变（手工调试） | 停 rAF 后不会重画，`setParam` 要补 `frame(0)`（§1 ⑤） |
| 写了 `noloop-step` 却被拒 | 宿主没有 `window.step` / `window.playFx`，改 `url-time`（§3） |

## 一、粒子：把「一堆离散小东西」做成一次 draw

一句话价值：一个发射器 = 一次 `drawArraysInstanced`，上千粒一次画完；粒子状态全部由（种子、出生时刻、参数）解析推导，CPU 侧不保存粒子数组，同一 t 两次绘制逐字节一致。

**它解决的五个手写痛点**：

| 手写时的问题 | 方法论上的解法 |
|---|---|
| 每粒一次 draw，几百粒就卡 | 共用 VAO/缓冲，用实例号当槽位号，一次实例化绘制 |
| 存 CPU 数组，倒带/冻帧就乱 | 槽位反解：第 i 槽当前该显示哪颗是算出来的，不是存的 |
| 环形缓冲要自己写 | 反解取「最新一颗」，超出池容量自然顶掉最老 |
| t=0 开场一片空白，要预热 | 允许出生时刻为负（t=0 之前就在天上） |
| 一次性爆发要加状态 | 发射窗口 `[emitT0, emitT1]`，窗口关后各自老去 |

**槽位反解（理解它才能正确调参）**：

```
lo    = max(emitT0, clock - life)      // 还活着的最早出生时刻
hi    = min(emitT1, clock)             // 已经发生的最晚发射
kf    = floor((hi*rate - sid) / pool)  // 本槽位「最新一颗」的代号
gid   = sid + kf*pool                  // 全局发射序号（可为负 = 开场前已在飞）
birth = gid / rate
age01 = (clock - birth) / life         // 活着 ⇔ birth∈[lo,hi] 且 age01∈[0,1]
```

**发射器形状**：点（可带小球抖动）、球面/球体、圆环、沿线段（射线/光束表面喷溅）、半球（贴地爆发）、范围盒（雪/雨这类范围填充）。方向模式：固定轴 + 锥角 / 径向 / 方位角。

**渲染样式**：圆点（受驱动点尺寸上限限制，巨大粒子改用 billboard 方片）、billboard 方片（尺寸可控，适合雪团/大颗粒）、沿速度拉伸的四边形（屏幕空间换算像素宽，适合火花拖尾）。色阶常用三档硬阶，混合可在加法/预乘之间切。

**运动**：解析积分，不迭代。阻尼 + 重力的位置/速度为闭式解，摆动也是 clock 的解析式，不存相位。

**验收方式（复用时照这个查）**：
1. 页面 HUD 常驻显示 **draw calls / 实例数 / 最小像素宽**，截图自带证据；
2. 同 t 两次绘制逐字节比对（差必须为 0），证明纯函数可复现；
3. 参数里带 `minPx`（默认 6）作为 720p 可读性的硬护栏，保证最细粒子不被缩没。

**已知限制**：多发射器是每 emitter 一次 draw call，不合并；`point` 样式受驱动点尺寸上限限制；拖尾是屏幕空间直线拉伸，不是真实轨迹。

**什么时候用**：火花、雪粒、冰屑、灰烬、碎屑、能量星点——任何「一堆离散小东西」。
**什么时候别用**：整体是一个连续形状的东西（光束主体、电弧骨架、爆光球）——那些走带子 / SDF 几何。判定线：**粒子是最小的离散单位，不是形状本身**。

## 二、带子：把「一串矩形」变成「一条带子」

核心做法：**拐点两侧共用同一对边界点**（miter join），相邻四边形必然共边——内侧不重叠（不产生加法混合的双线亮结），外侧不留缺口。

**为什么需要它**：逐段独立算法线时，拐点两侧边界点不重合：

| 位置 | 症状 |
|---|---|
| 内拐角 | 两个四边形压在一起 → 加法混合下亮度翻倍 = 双线 / 亮结 |
| 外拐角 | 两块之间空出月牙 → 露缺口（带子像被剪了一刀） |

来源方实测（S 形 48 点、半宽 24px）：逐段实现重叠 206 格（1.54%）+ 漏空 224 格；改成共享边界点后 0 / 0。

**能力边界**：2D 折线按设备像素给每点半宽，支持 `legacy / miter / round / bevel` 四种连接方式（`legacy` 用来做 A/B 复刻）；3D 版同一套拐角内核，差别只在边界点方向从哪来（2D 用切线的法线，3D 用叉积对相机）。miter 过长时退化 bevel 防长矛；半宽超过曲率半径时内角要钳制，防蝴蝶结。

**两个静默坑（真踩过，不报错但什么都没画）**：
1. `drawElements` 的索引类型必须读工具算出来的 `indexType`（按顶点数自动选 u16/u32），写死 `UNSIGNED_INT` 会读到越界索引 → 静默空白；
2. 3D 用平铺模式时 `u` 会 >1，片元两端收口的 `discard` 会把整条吃掉 → 全空。

**验收方式：A/B 红青对照**。同一折线分别用 `legacy` 与 `miter` 两套算法、同机位同参数各出一张图，叠成红/青双通道：重合处呈灰，内拐角的亮结与外拐角的缺口会分别跳成红或青。再配一张覆盖计数图（逐像素数被覆盖几次）作为客观证据——重叠与漏空都能量化，不靠肉眼猜。

**已知边界**：过尖折返（半宽 > 曲率半径）时内角必然收窄；`round` / `bevel` 按 SVG `stroke-linejoin` 语义主动切外角尖，「覆盖比 miter 少」是设计不是漏。

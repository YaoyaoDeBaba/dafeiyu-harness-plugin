## 一、评测页契约（示例宿主的落地形状）

```js
window.FxEffect = {
  name: 'xxx',
  params: { key: { value, min, max, step, label } },  // 自动生成滑块
  init(ctx),        // 一次：建几何、编译 shader
  draw(ctx, t)      // 每帧：t ∈ [0,1] 技能进度
};
```

ctx 提供：`gl / canvas / proj / view / vp / eye / aspect / duration / params / origin / target / dir / GLSL_COMMON / program(vs, fs, name)`。
GL 初始状态：深度 ON / LEQUAL / **不写深度**；混合 RGB=(SRC_ALPHA, ONE)、alpha=(ONE, ONE_MINUS_SRC_ALPHA)。要改混合自己在 draw 里改，画完还原。shader 第一行自带 `#version 300 es`。

验收页是宿主提供的干净模板页（不随本包分发）；批量出图由宿主自己的脚本完成。契约只规定「一个 effect = 一个入口 + 一组参数 + init/draw」，具体文件名与页面路径由宿主决定。

> 铁律提醒：`draw()` 第一件事必须是 `gl.useProgram`（漏了就灰板 + t 无反应，见 `glsl-guardrails.md` 铁律 1）。

## 二、带状网格生成器（Ribbon / Trail）

**解决什么**：所有「沿一条中心线铺一条带子」的部件——光束、闪电、拖尾、能量鞭、地面轨迹。以前每个 effect 手拼顶点算拐角，现在一次调用。
**工具本体**：由来源方维护，不在本包内（来源与许可未确认，本包只吸收用法要点，见 `runtime-libs.md`）。

**典型用法场景**：
- 光束主体：中心线 = 起点→终点直线，宽度包络 = 锥形收尖；
- 闪电：中心线 = 每帧重掷的折线（动态更新，不重建 buffer）；
- 拖尾：中心线 = 历史位置队列。

## 三、粒子框架

**解决什么**：火花、雪粒、冰屑、灰烬、碎屑——所有离散颗粒。一次 draw 上千粒，同种子可复现。
**工具本体**：由来源方维护，不在本包内（来源与许可未确认，本包只吸收用法要点，见 `runtime-libs.md`）。

**典型用法场景**：
- 射线表面喷溅：沿线段发射器 + 速度锥角；
- 命中爆发：点发射器 + 半球 + 强阻尼；
- 环境雪粒：范围发射器 + 重力 + 长生命。

## 四、参数与验收工具

| 工具 | 用途 |
|---|---|
| 多页面批量出图脚本 | 多页面一次连接出图（固定少量连接，抗限流） |
| 标准截图时相计划 | 固定若干时相的计划（如 8 点 / 6 点 / 4 点），保证不同轮次可比 |

## 五、量具 ↔ 验收指标（2026-11-15 补）

写需求书第十节「怎么量」那一列时，先看有没有现成量具；**没有量具的指标要么自己写十行脚本，要么老实标「暂无口径」**（不许编数）。

| 验收指标（§3.5 的客观量） | 现成量具能答吗 | 不能的话怎么补 |
|---|---|---|
| 覆盖率 / 亮区面积比 | ✅ PNG 几何占比 | —— |
| 主角与背景亮度差 | ✅ 亮度差量具 | —— |
| 色相分散度 / 灰褐占比 | ✅ 色种统计 + 色相直方图 | 需要按桶看分布时自己拉直方图 |
| 边缘过渡宽度（px） | ❌ | 沿法线扫 alpha 剖面，Sobel 或逐像素判 25%/75% |
| 局部对比度（分块标准差） | ❌ | 解 PNG → 8×8 分块 → 逐块标准差 → 取中位数 |
| 可辨档数 / 核缘 alpha 比 | ❌ | 沿横截面取一条剖面，数过阈次数 / 比值 |
| 离散件数（连通域计数） | ❌ | 二值化 + 连通域标记 |

> 规律：**面积类、亮度类、色类**基本有现成量具；**边缘、剖面、连通域**这三类没有，需要自己写（都很短）。所以需求书里优先挑"能量"的指标，而不是"只能眼看"的形容词——这也正是 §3.5 存在的理由。
